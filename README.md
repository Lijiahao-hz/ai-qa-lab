# ai-qa-lab

我的测试练手仓库。零基础起步，第 1 天。

## 这里有什么

- `calc.py`：一个被测试的「被测对象」，四个小函数
- `tests/test_calc.py`：给这四个函数写的 8 条测试用例

不用看懂全部，先跑起来。

## 第一步：跑通（看到绿色）

在终端里进入这个文件夹，依次输入：

```bash
cd ai-qa-lab
python3 -m pip install pytest
python3 -m pytest -v
```

最后一行应该出现 `8 passed`。**这就是"全绿"。**

## 第二步：故意改坏（看到红色）

打开 `tests/test_calc.py`，找到这一条：

```python
def test_add_two_positive_numbers():
    assert add(2, 3) == 5
```

把 `== 5` 改成 `== 6`，保存，再跑一次 `python3 -m pytest -v`。

你会看到一条 `FAILED`，并且它明确告诉你：期望 6，实际是 5。

**这一步是整个学习的转折点。** 报错不是"你错了"，是电脑在告诉你哪里不对。

## 第三步：改回来（重新变绿）

把 `== 6` 改回 `== 5`，再跑一次，又回到 `8 passed`。

## 你现在已经理解的三件事

1. 测试就是一句 `assert 期望 == 实际`
2. 绿 = 通过，红 = 不通过，红字里写着差在哪
3. 你不必先学会写代码，也能读懂一句断言在干什么

## 接下来一周要做的

把 `calc.py` 里的函数交给 AI（通义灵码 / Cursor），让它给你生成新的测试用例，
你负责判断"这条用例测得对不对"。

**写代码交给 AI，判断对错交给你。这是你的分工。**
